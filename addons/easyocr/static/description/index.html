EasyOCR

Turn a PDF invoice into an accounting entry, without retyping it

Drop a supplier invoice or an expense receipt and review what was read from it before it becomes an entry in Odoo. The document stays visible from the moment it is uploaded, so a file that fails to be read can be retried instead of disappearing.

What it does

Reads the document

Supplier, tax number, document number, date and totals are read from the file and offered for review. Nothing is posted without a person looking at it.

Remembers each supplier

Some suppliers send the same layout every month. Once a layout is recognised, the same fields are read from it again, so the review gets shorter over time.

Works on Odoo Community

Installs on Odoo Community 18.0 and 19.0. It does not require Odoo Enterprise and it does not need you to open an account with an AI provider: the module is configured once and works from there.
